01 / TODAY

One daily plan from the week you confirmed.

Today uses your schedule, goals, recovery, nutrition, and approved adjustments to create 3–5 clear tasks. If generation fails, a valid existing plan stays in place.

  • Clear task priorities
  • Minimum versions for hard days
  • Completed items stay completed
02 / WORKOUT

Generation grounded in what you actually did.

Completed sets, recent sessions, available equipment, pain context, and Athlete Week become one evidence packet. The result explains why it fits the day.

  • Exact set targets and load units
  • Schedule-fit label and explanation
  • Current workout preserved on failure
03 / COACH

Coach advises. Workout and Today execute.

Coach can explain, suggest, and remember narrowly scoped context. It cannot silently generate, edit, replace, log, refresh, or complete app state from chat.

  • Editable typed memory
  • Temporary context can expire
  • Execution confirmed on its destination screen
