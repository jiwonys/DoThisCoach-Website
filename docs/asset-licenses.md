The immersive homepage does not introduce third-party photographs, 3D models, textures, icons, stock footage, or audio.

No new ownership claim is made by this redesign. Their existing repository provenance and usage permissions remain authoritative.

## Generated visual assets

- `assets/dothis-logo-192.png` is a mechanically resized derivative of the existing DoThis logo, produced for favicon performance.
- The technical-fabric surface, connective lines, Today seam, anchors, and all spatial geometry are generated in code.
- The custom tension shader was written for this project and uses no copied ShaderToy or third-party shader source.

## Runtime dependencies

Open-source runtime packages are managed through `package-lock.json`. They are code dependencies, not brand or visual assets. No external asset CDN is required by the homepage.
