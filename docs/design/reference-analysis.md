# Reference analysis

Browser inspection completed 2026-08-29 at 390 × 844 and 1440 × 1000.

## Current DoThis website

Observed:

- Warm light first viewport with a capsule navigation bar, oversized black/green display type, one primary CTA, and a real app screen placed at large scale.
- Mobile keeps the headline and CTA immediately visible, then introduces the product screen below the fold.
- Existing identity already uses deep green, mint, warm off-white, editorial spacing, and a dark product UI.

Implication:

- A redesign must add a stronger sport-recognition mechanism and clearer sport-specific evidence. Merely changing colors or animating the current composition would be a cosmetic reskin.

## Subscrr reference

Observed:

- Warm neutral canvas, compact capsule navigation, oversized multi-line headline, strong red action color, and early product imagery.
- Product scale and whitespace make the first viewport easy to parse before detailed explanation.
- Mobile preserves hierarchy and product visibility instead of hiding essential content behind animation.

Principles extracted:

- Let one proposition dominate the first screen.
- Place tangible product evidence near the proposition.
- Keep navigation and primary action visually simple.
- Use restrained motion and strong spacing rather than a dense feature-card wall.

Not copied:

- Subscrr’s brand, exact text, colors, photography, source code, or privacy claims.

## Shipping App Store page

Observed:

- Apple displayed the current DoThis title, icon, category, and screenshot gallery.
- General gallery leads with a multi-sport athlete board, then Today, workout/Coach, and food/progress proof.
- Owner-controlled local App Store exports provide higher-quality source assets than the public preview.

## Phase 1 design consequence

Both prototypes use Tennis as the representative state and Basketball as the second proof state. Each selector changes athlete board, product board, benefit sentence, accent, and fixed App Store destination together.
