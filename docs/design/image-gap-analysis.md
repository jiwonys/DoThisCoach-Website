# Image gap analysis

## Phase 1

No paid image generation is required. Approved vertical App Store boards exist for General, Soccer, Basketball, Pickleball, Tennis, and Volleyball, and every sport has real simulator product evidence. Phase 1 prototypes use optimized derivatives of those assets.

## Possible Phase 2 gaps

- Standalone landscape athlete/environment photographs for each sport. Current sport-specific athlete art is embedded inside approved vertical App Store marketing boards.
- Optional transparent athlete cutouts if the approved direction requires subject overlap outside a rectangular board.

These are design-dependent gaps, not automatic generation work. If the approved homepage genuinely needs them, prepare one brief per missing sport and propose a finite `gpt-image-2` batch with current cost before making a paid request.

## Explicit non-gaps

- Product screens: real simulator captures already exist.
- App Store compositions: approved boards already exist.
- Logo/icon: approved source exists and must not be regenerated.
- Testimonials, customer portraits, metrics, or founder imagery: absence is not permission to fabricate them.
