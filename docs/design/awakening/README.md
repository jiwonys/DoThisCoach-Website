# Second Awakening homepage

## Direction

The user rejected the information-first Field Manual homepage and explicitly asked for a premium, mysterious athlete identity experience: a second awakening. The new homepage sells desire before explanation.

Visible promises:

- “You can be a lethal athlete.”
- “You just need to train like one.”
- “This is your second awakening.”
- “Train with us. Become a lethal athlete.”

## Narrative

1. A multi-sport athlete portrait emerges from nocturnal darkness beside one lethal promise.
2. The manifesto confronts dormancy without product explanation.
3. A sport selector changes approved athlete photography, one emotional line, URL state, accent, and App Store destination together.
4. Three real screens provide a restrained glimpse rather than a feature tour.
5. The close commands the athlete to wake up and train.
