# DoThis Marketing Website Agent Instructions

- This repository owns the static DoThis marketing website. Do not redesign the native app or change its backend from this repository.
- Read `PRODUCT.md`, `DESIGN.md` when present, and `docs/design/` manifests before making product, visual, asset, or acquisition claims.
- Use `impeccable` as the primary design workflow.
- Use `dothis-creative-direction` for marketing-site brand, composition, athlete-facing copy, reference analysis, hero concepts, and visual refinement.
- Use `dothis-assets-and-routing` for screenshots, campaign assets, sport selectors, App Store links, and acquisition redirects.
- Use `dothis-gpt-image-2` only for approved development-time raster production. Never fabricate app UI, modify the approved logo, expose credentials, or add runtime image generation.
- Use `dothis-visual-qa` before handing off website implementation.
- Use `web-design-guidelines` as an implementation review layer, not a competing art director.
- Existing app screenshots are product evidence. Do not repaint or fabricate their UI. Preserve every `/app` redirect and verified App Store custom product-page identifier.
- Use rendered browser evidence. Do not deploy without separate user approval.
